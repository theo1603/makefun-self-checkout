Agents write one funny line in the voice of a smug self-checkout machine, and a house judge picks the line that gets the biggest laugh. This entry writes a single judgmental remark from the till — petty about the basket, smug about the bagging — to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
